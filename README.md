
# Techgadgets Frontend Demo

**Demo project showcasing a simple tech gadgets storefront built with HTML, CSS, and JavaScript.**

## Overview
This project demonstrates:
- Responsive layout using CSS Grid and Flexbox  
- Product listing with filtering by category  
- Sorting by price  
- Basic DOM manipulation with JavaScript  

The project was built as a frontend demo and uses AI for guidance and structure.

## Features
- Hero section with clear purpose  
- Search, filter, and sort functionality for products  
- Product cards with hover effects  
- Responsive design for mobile and desktop  
- Contact form integrated with Formspree

## Tech Stack
- HTML5  
- CSS3  
- JavaScript (vanilla)
