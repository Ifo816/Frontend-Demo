# Techgadgets Frontend Demo

**Live Demo:** ([https://yourproject.netlify.app](https://demoproductlandingpage.netlify.app/#products))

A simple tech gadgets storefront showcasing **responsive design, interactive UI, and DOM manipulation** using HTML, CSS, and JavaScript.

## Overview
This project demonstrates:
- Responsive layout using CSS Grid and Flexbox  
- Product listing with filtering by category  
- Sorting by price  
- Dynamic DOM manipulation with JavaScript  

Built as a **frontend demo**, with guidance from AI tools to streamline development.

## Features
- Hero section with clear messaging  
- Search, filter, and sort functionality for products  
- Product cards with hover effects and responsive design  
- Contact form integrated with Formspree  

## Tech Stack
- HTML5  
- CSS3  
- JavaScript (vanilla)  

## Notes
This is a **demo project** meant to showcase frontend skills.  
It can be extended with additional features like cart functionality, backend integration, or enhanced styling.
